# xdg-ai-tools

两个实用的纯前端 AI 工具（单文件 HTML，零依赖，打开即用）：

| 文件 | 功能 |
|------|------|
| `AI缓存命中计算器.html` | AI 缓存命中计算器：计算大模型/推理服务缓存命中率相关的指标 |
| `用眼时长提示器.html` | 用眼时长提示器：定时提醒用眼休息，保护视力 |

## 使用方式

直接双击 HTML 文件用浏览器打开即可，无需安装任何依赖。

## 项目结构

```
xdg-ai-tools/
├── AI缓存命中计算器.html
├── 用眼时长提示器.html
└── README.md
```

## 技术栈

纯原生 HTML + CSS + JavaScript，内联 SVG 图标，无任何外部依赖。
