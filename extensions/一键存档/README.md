# 一键存档 · Web Note Saver

选中网页文字按 `Alt+Q` 一键存入本地笔记；在 Word / PDF / 微信等其他软件里复制的文字也会自动入档。全程不需要复制粘贴来回切换，所有数据只存在你自己电脑里。

```
┌──────────────────────┐        ┌─────────────────────────────┐
│  浏览器扩展（网页）    │        │  本地存档工具（Python 常驻）   │
│  选中文字 → Alt+Q     │ ─HTTP─▶ │  · HTTP 服务（接收扩展内容）   │
│  (带 token 校验)      │        │  · 剪贴板监听（其他软件复制）   │
└──────────────────────┘        │  · 去重 + 智能过滤             │
                                │  · 托盘菜单（暂停/打开笔记）     │
                                └──────────────┬──────────────┘
                                               ▼
                                        notes.md（Markdown）
```

## 项目结构

```
web-note-saver/
├── 一键存档.exe              # 打包好的本地工具（免装 Python，双击即用）
├── saver/                    # 本地工具源码（Python）
│   ├── saver.py              # 主程序：HTTP 服务 + 剪贴板监听 + 托盘
│   ├── start.bat             # 从源码启动（自动安装依赖）
│   ├── config.example.json   # 配置模板（首次启动会自动生成 config.json）
│   └── config.json           # 实际配置（含访问令牌，不入库）
└── webext/                   # 浏览器扩展（Edge / Chrome）
    ├── manifest.json
    ├── background.js         # 快捷键监听、发送内容
    ├── content.js            # 读取页面选中文字
    ├── options.html          # 设置页（填访问令牌）
    └── icons/
```

> 仓库中不包含 `config.json`（含本机路径与访问令牌）和 `我的笔记.md`（个人笔记内容），
> 已通过 `.gitignore` 排除，首次运行时自动生成。

## 快速启动（推荐）

双击 **`一键存档.exe`**（已打包，无需安装 Python）。黑窗口出现并显示访问令牌，即启动成功。

> 从源码运行：双击 `saver\start.bat`（需要电脑已安装 Python，首次运行会自动装依赖）。

## 安装步骤（约 5 分钟）

### 第 1 步：安装 Python（仅源码方式需要）

用 `一键存档.exe` 可跳过本步。若要从源码运行：到 https://www.python.org/downloads/ 下载 Windows 安装包，
**安装时务必勾选 "Add python.exe to PATH"**，装完重启终端即可。

### 第 2 步：启动本地存档工具

双击 `一键存档.exe`（推荐），或双击 `saver\start.bat`（源码方式，首次运行会自动安装依赖，需联网约 1 分钟）。

启动后窗口会显示：

```
  笔记文件 : C:\...\我的笔记.md
  服务地址 : http://127.0.0.1:8631
  访问令牌 : <随机生成的令牌>        ← 记下这个令牌
```

**这个窗口要一直开着**（最小化即可，托盘里有图标）。

> 想让笔记文件放别处？编辑 `saver\config.json`，把 `notes_path` 改成任意路径，例如
> `"notes_path": "D:\\我的笔记\\notes.md"`，保存后重启工具。放在网盘同步目录里还能跨设备备份。

### 第 3 步：安装浏览器扩展

1. 打开 Edge（或 Chrome），地址栏输入 `edge://extensions`（Chrome 用 `chrome://extensions`）
2. 打开右上角「开发人员模式」开关
3. 点「加载解压缩的扩展」，选择本项目的 `webext` 文件夹
4. 工具栏会出现「一键存档」图标

### 第 4 步：填写令牌（一次性）

点扩展图标 →「选项」（或右键图标 → 选项），把启动窗口里的**访问令牌**粘贴进去，点「保存设置」，再点「测试连接」确认显示"连接成功"。

## 使用

| 场景 | 操作 |
|------|------|
| 网页 | 选中要保存的文字 → 按 `Alt+Q`（Windows 通知提示"已保存"） |
| Word / PDF / 微信等 | 直接复制（Ctrl+C），文字会自动入档（带智能过滤） |
| 网页也可 | 选中文字后直接点工具栏的扩展图标 |

- 所有内容按时间倒序追加到 `notes.md`，每条记录自动带**日期时间、网页标题、来源链接**。
- 内容与最近 5 秒内保存的相同会自动跳过（防重复）。
- 系统托盘右键图标可：打开笔记 / 打开配置 / 暂停剪贴板 / 退出。

## 常见问题

**Q：按 Alt+Q 提示"连接失败"？**
本地工具没在运行。双击 `start.bat` 重新启动，然后在扩展选项页「测试连接」。

**Q：想换快捷键？**
`edge://extensions` → 找到「一键存档」→「键盘快捷键」里修改。

**Q：复制的验证码 / 金额 / 链接被误存了？**
工具默认忽略：少于 15 字的、纯链接、纯数字。可在 `config.json` 里调 `min_length`、`ignore_urls`、`ignore_pure_digits`。

**Q：复制的内容没自动入档？**
可能被误判重复或太短；也可以在托盘菜单点「暂停剪贴板」再恢复试试。

**Q：笔记文件被别人改过，会丢吗？**
工具用追加模式写入，不会覆盖已有内容。但建议写笔记时不要同时打开 notes.md 编辑。

## 安全说明

- 工具只监听 `127.0.0.1`（仅本机），外部网络访问不到。
- 写入接口需要令牌校验，其他网页无法偷偷往里写内容。
- 所有文字只存在本地 `notes.md`，不联网、不上传。
