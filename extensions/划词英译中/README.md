# 划词翻译 · 英译中助手（Edge 扩展）

选中网页上的英文文字，一键翻译为中文。基于 Manifest V3 开发，兼容 **Microsoft Edge** 与 **Chrome**。

## 功能

- 🖱️ **划词翻译**：在网页上选中英文，自动弹出「译」按钮，点击即译
- 📋 **右键翻译**：选中文字后右键 →「英译中 · 翻译选中文字」
- ⌨️ **快捷键**：`Alt + T` 翻译当前选中的文字
- 🎯 **结果卡**：展示原文与译文，支持 **复制译文 / 替换原文 / 朗读译文**（中文语音朗读）
- 🌐 **三种引擎**：自动免费引擎（开箱即用）、百度翻译（国内快）、OpenAI 兼容接口（质量最高）
- 🔁 **双向翻译**：默认自动检测（英文→中文），也可手动输入翻译、中文→英文
- 🧩 **长文分段**：超长文本自动分段翻译后合并

## 安装步骤（Edge）

1. 打开 Edge 浏览器，地址栏输入 `edge://extensions/` 回车
2. 打开左下角 **「开发人员模式」** 开关
3. 点击 **「加载解压缩的扩展」**
4. 选择本项目文件夹（内含 `manifest.json` 的那个目录）
5. 安装完成，工具栏出现蓝色「译」图标

> Chrome 用户同理：`chrome://extensions/` → 开发人员模式 → 加载已解压的扩展程序

## 使用方法

| 方式 | 操作 |
| --- | --- |
| 划词翻译 | 选中英文 → 点弹出的「译」按钮 |
| 右键菜单 | 选中英文 → 右键 →「英译中 · 翻译选中文字」 |
| 快捷键 | 选中英文 → `Alt + T` |
| 手动翻译 | 点工具栏「译」图标 → 输入文字 → 翻译 |
| 朗读译文 | 结果卡点「朗读」（读中文） |
| 替换原文 | 结果卡点「替换原文」直接用译文覆盖网页文字 |

## 翻译引擎配置

默认「自动」引擎**零配置即可用**（MyMemory 免费接口，失败自动切 Google 免费接口）。

国内网络推荐配置 **百度翻译**（稳定快速，标准版免费）：
1. 打开 [百度翻译开放平台](https://fanyi-api.baidu.com/) 注册登录
2. 「管理控制台」→ 创建应用（服务选择「通用翻译」）
3. 获取 **AppID** 与 **密钥**
4. 扩展设置页 → 选择「百度翻译」→ 填入并保存

追求翻译质量可配置 **OpenAI 兼容接口**（支持 DeepSeek / 通义千问 / Kimi 等任意兼容服务）：
- Base URL：如 `https://api.deepseek.com/v1`
- API Key：你的密钥
- Model：如 `deepseek-chat`

## 常见问题

**Q：点击「译」按钮提示翻译失败？**
A：免费接口偶发超时，重试即可；频繁失败请到设置页配置百度翻译（国内最稳）。

**Q：某些页面（如浏览器内置页面、PDF 查看器）不弹按钮？**
A：浏览器安全限制，扩展无法在 `edge://` 等内置页面运行。PDF 可在右键菜单翻译。

**Q：如何卸载？**
A：`edge://extensions/` → 找到本扩展 → 移除。

## 隐私说明

- 所有配置（密钥）仅保存在本地浏览器（`chrome.storage.sync`）
- 选中的文字仅发送给你选择的翻译服务商用于翻译，无任何第三方统计
